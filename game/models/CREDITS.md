# Tiny Planet art credits

All models come from Sketchfab. Gilad picked and downloaded them; the game shrinks them for the browser
(fewer triangles, smaller textures, some turned to face forward). Every model here is OK to use in a game that makes money:
CC BY 4.0 (credit the maker) or Sketchfab Standard (use in a project, no reselling the file).
